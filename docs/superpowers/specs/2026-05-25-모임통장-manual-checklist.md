# 모임통장 — Manual Test Checklist

라이브 Discord 서버에서 v1 배포 전 1회 실행. 토큰을 가진 사용자가 직접 검증.

## Setup

- [ ] 테스트용 Discord 서버에 봇 초대 (Manage Channels 권한 포함)
- [ ] 빈 텍스트 채널 1개 준비
- [ ] 일반 멤버 1명 + 관리자 1명 확보

## 시나리오 1: 등록

- [ ] 일반 멤버가 `/모임통장 등록` → ephemeral 거부 "관리자만..."
- [ ] DM 채널 `/모임통장 등록` → ephemeral 거부 "서버 채널에서만..."
- [ ] 관리자가 채널에서 `/모임통장 등록` → 성공, 5분 내 채널명 `💰-0원`
- [ ] 같은 채널에 또 `/모임통장 등록` → ephemeral 거부 "이미 등록..."
- [ ] 같은 서버 다른 채널에서 `/모임통장 등록` → ephemeral 거부 "이미 #이전채널..."

## 시나리오 2: 입금

- [ ] `/모임통장 입금 금액:50000 메모:"지각벌금" 날짜:2026-11-28` → 성공 ephemeral, 채널 메시지 `📥 +50,000원 · 지각벌금 · 2026-11-28 · 잔액: 50,000원`
- [ ] `/모임통장 입금 금액:30000` (메모/날짜 생략) → 성공, 채널 메시지에 오늘 날짜
- [ ] `/모임통장 입금 금액:0` → ephemeral 거부 "1원 이상..."
- [ ] `/모임통장 입금 금액:-100` → ephemeral 거부
- [ ] `/모임통장 입금 금액:1000 날짜:2026-13-32` → ephemeral 거부 "YYYY-MM-DD..."
- [ ] `/모임통장 입금 금액:1000 메모:"x"*201` → ephemeral 거부 "200자 이하..."

## 시나리오 3: 출금 (overdraft 거부)

- [ ] 잔액 80,000원 상태에서 `/모임통장 출금 금액:200000` → ephemeral 거부 "잔액(80,000원)보다 큰..."
- [ ] `/모임통장 출금 금액:30000 메모:"부스트"` → 성공, 잔액 50,000원

## 시나리오 4: 채널명 갱신 (rate-limit)

- [ ] 5건 입금을 연속 빠르게 (1분 내) → 채널명은 1회만 rename (코얼레싱)
- [ ] 10분 동안 거래 추가 등록 → 채널명 갱신 최대 2회 (Discord 한도)

## 시나리오 5: 관리 UI

- [ ] 일반 멤버 `/모임통장 관리` → 권한 거부
- [ ] 거래 없는 등록 채널 `/모임통장 관리` → ephemeral "등록된 거래가 없습니다."
- [ ] 거래 있는 채널 `/모임통장 관리` → 날짜 셀렉트 표시
- [ ] 날짜 선택 → 항목 셀렉트 + [↩️ 다른 날짜] 버튼
- [ ] [↩️ 다른 날짜] → 날짜 셀렉트 복귀
- [ ] 항목 선택 → 디테일 임베드 + [✏️ 수정][🗑️ 삭제][↩️ 뒤로]
- [ ] [↩️ 뒤로] → 항목 셀렉트 복귀

## 시나리오 6: 수정

- [ ] [✏️ 수정] → Modal 팝업 (금액·메모·날짜 prefilled)
- [ ] 금액을 0으로 → ephemeral 거부
- [ ] 날짜를 `2026-13-99`로 → ephemeral 거부
- [ ] 메모만 변경, 금액 유지 → ephemeral 성공, 채널 메시지 edit됨, 잔액 변동 없음
- [ ] 금액 증가 → 잔액 재계산 + 5분 내 채널명 갱신
- [ ] 금액을 너무 크게 변경 → 잔액 음수 → ephemeral overdraft 거부, 원복

## 시나리오 7: 삭제 (hard delete)

- [ ] [🗑️ 삭제] → ephemeral 확인 임베드 + [예, 삭제합니다][취소]
- [ ] [취소] → ephemeral "취소되었습니다."
- [ ] [예, 삭제합니다] → ephemeral "삭제 완료", 채널 자동 메시지 사라짐, 잔액 재계산, 채널명 갱신
- [ ] 같은 거래에 다시 [🗑️ 삭제] → ephemeral "이미 삭제됨"

## 시나리오 8: 회귀 — RSS 무영향

- [ ] `/ping` → "pong from eu-ssya-bot"
- [ ] `/rss add <URL>` → 정상 추가
- [ ] `/rss list` → 정상 조회
- [ ] `/rss remove <URL>` → 정상 삭제
- [ ] 봇 재시작 후 RSS 폴링 정상 동작

## 시나리오 9: 봇 권한 없음

- [ ] 봇에서 Manage Channels 권한 회수 후 `/모임통장 등록` 시도 → ephemeral "봇에 '채널 관리' 권한이..."

## 시나리오 10: View timeout

- [ ] `/모임통장 관리` 실행 후 10분 동안 클릭 안 함 → View 비활성화

## 합격 기준

위 모든 항목 통과 시 v1 배포 가능. 한 가지라도 fail 시 해당 task로 돌아가 디버그.
